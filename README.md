# VetNote

[English version](README.en.md)

**En développement · Application mobile pour vétérinaires de terrain**

VetNote est un projet d’application mobile conçu pour faciliter l’organisation et la prise de notes lors des interventions vétérinaires sur le terrain.

## Le contexte

Sur le terrain, le réseau n’est pas toujours disponible et chaque étape supplémentaire ralentit le travail. Les informations prises pendant une intervention doivent rester faciles à saisir, à retrouver et à protéger.

VetNote explore une expérience adaptée à ces contraintes réelles.

## Principes du projet

- Fonctionner en priorité hors connexion.
- Proposer une interface lisible et rapide à utiliser sur le terrain.
- Réduire la double saisie après une intervention.
- Structurer les informations sans alourdir le travail du vétérinaire.
- Protéger les données enregistrées sur l’appareil.
- Garder le professionnel maître du contenu de ses notes.

## Statut

VetNote est actuellement **en développement**. Le projet évolue encore et aucune date de disponibilité publique n’est annoncée.
